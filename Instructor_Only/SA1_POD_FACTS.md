## Learning Plan 9 specifics (Monitoring and Troubleshooting; Competency 9; capstone)
- Competency 9 is assessed in LP9. Competency 9: "Monitor and troubleshoot server performance." Criteria 9.1 you interpret performance and event data; 9.2 you identify and resolve resource bottlenecks. Objectives 9.a Use Performance Monitor, data collector sets, Task Manager and Resource Monitor; 9.b Manage and filter event logs; 9.c Apply a structured troubleshooting method to performance, connectivity and name resolution problems.
- Troubleshooting method: the CompTIA Server+ SK0-005 six steps, used with the official wording everywhere: 1 Identify the problem and determine the scope; 2 Establish a theory of probable cause (question the obvious); 3 Test the theory to determine the cause; 4 Establish a plan of action to resolve the problem (notify impacted users); 5 Implement the solution or escalate; 6 Verify full system functionality and, if applicable, implement preventive measures; plus perform a root cause analysis, and document findings, actions and outcomes throughout the process.
- Lab 9.1 (snapshot SA1-DOMAIN, SRV01): Task Manager (Processes, Performance, Details with the Command line column), Resource Monitor (CPU, Memory, Disk, Network; filter by process), Performance Monitor: counters \Processor(_Total)\% Processor Time, \Memory\Available MBytes, \Memory\Pages/sec, \PhysicalDisk(_Total)\Avg. Disk sec/Read, \PhysicalDisk(_Total)\% Idle Time, \PhysicalDisk(_Total)\Avg.
